Habilidades

JavaScript

JavaScript é uma das, se não a principal ferramenta do frontend onde a "magia" realmente acontece. Fiquei encantado com a capacidade do JS de dar vida a tudo, e isso despertou uma grande paixão em mim. Hoje em dia, é a linguagem que mais estudo e na qual busco me aperfeiçoar continuamente.

HTML5

HTML foi a primeira linguagem que aprendi na programação e é fundamental para a estruturação dos meus projetos. Embora já tenha um conhecimento avançado, continuo buscando aprender e me atualizar sobre novas técnicas e padrões para aprimorar minhas habilidades e garantir projetos eficientes.

CSS3

CSS foi uma das ferramentas que mais me chamou a atenção durante meus estudos e projetos. Com ele, consigo transformar ideias estáticas em designs mais fluídos e atraentes, aprimorando a aparência e a experiência do usuário.

GitHub

GitHub é a plataforma ideal para armazenar meus projetos e colaborar com os de outras pessoas. É onde busco projetos para contribuir com a comunidade e aprimorar minhas habilidades, além de ser o local onde guardo e gerencio meus próprios códigos.

RPA

Tenho experiência com automação utilizando UiPath, criando bots para otimizar tarefas repetitivas e aumentar a eficiência. Sei integrar automações com diferentes sistemas e utilizo boas práticas para garantir processos ágeis e confiáveis. Sempre buscando aprender mais sobre RPA e explorar novas possibilidades!

Git

Como mencionei sobre o GitHub, não poderia deixar de citar o Git. Ele é essencial para realizar todas as operações no GitHub, permitindo o registro detalhado das mudanças e coordenando o trabalho de múltiplas pessoas. Isso simplifica significativamente o trabalho remoto e a colaboração em projetos.
